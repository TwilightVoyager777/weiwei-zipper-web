# 06 · 信任建设与关于页升级（E-E-A-T）

> 前置阅读：`00-总览与执行顺序.md`。
> 类型：代码 + 用户配合（照片与事实信息）。执行 agent 先完成能做的代码部分，把「用户提供项」整理成清单交付。
> 背景：B2B 采购决策的核心疑虑是"你是真工厂还是贸易商？"。Google 的 E-E-A-T 评估也在看内容背后是否有真实的人和组织。目前 About 页只有一张办公室照片、无真人、无证书，是全站信任链最薄弱的一环。

## 一、关于页（/about）改造

文件：`src/app/[locale]/about/page.tsx`，文案在 `src/site-data/site-content.ts`（5 语言）。

### 1. 创始人/团队真人区块（新增，最重要）
- 结构：照片 + 姓名 + 角色 + 两三句个人视角的话（"1992 年入行，最在意的是……"）
- 位置：公司介绍段落之后
- **用户提供**：1-2 位真人（老板/外贸负责人）的姓名、照片、一句话理念；照片正面自然光即可，不要证件照风格
- 多语言：姓名可用拼音 + 中文并列（`Wei Wei (伟伟)` 式），文案 5 语言

### 2. 时间线区块（新增）
1992 创立 → 扎根义乌国际商贸城三区 → 扩展金属/树脂/尼龙三大线 → 服务 50+ 国家。4-5 个节点，每节点一行事件；`TODO(用户确认): 各节点真实年份与事件`

### 3. 工厂/门店照片墙（替换现在的单张办公室照）
- 布局：横向 2×3 或滚动相册，复用 `ZoomableImage` 组件支持点开放大
- **用户提供**（拍摄清单，手机即可，横构图、白天自然光、画面里避免无关杂物）：
  1. 车间/生产设备运转中（最有说服力的一张）
  2. 码装卷/成品的仓储堆放
  3. 质检/验货过程（有人在操作）
  4. 打包出货（贴好唛头的外箱最佳）
  5. 商贸城门店门头（含店招）
  6. 样品墙/色卡墙
- 照片到位后走 WebP 压缩标准（≤1600px q82）放 `public/factory/`
- 每张配一行 5 语言说明文字（"齿色电镀后的抽检" 这种具体描述，不写"我们很专业"式空话）

### 4. 证书区块（有则加）
- **用户确认**：是否有 OEKO-TEX、BSCI、SGS 检测报告、营业执照公示意愿等
- 有：缩略图 + 名称，点开放大（ZoomableImage）；没有：跳过此节，**不要放模糊的假证书样式占位**

### 5. 社媒卡片降噪（顺手修）
现状：TikTok 黑 / YouTube 大红 / Instagram 彩虹渐变 / Facebook 蓝四种饱和色堆在一起，像广告位。改为：白底卡 + 各平台小 logo + 平台名 + 一句说明，hover 边框变品牌蓝。链接与现有一致。

### 6. 响应承诺具体化
把「工作时段内优先回复」升级为具体承诺（如「工作日 12 小时内回复询盘」），顶栏和 contact 页同步；`TODO(用户确认): 承诺时限`

## 二、博客作者体系（配合 03/04 内容任务）

1. `content/blog/` frontmatter 的 `author` 从 `Weiwei Zipper Team` 换成真人（如外贸负责人），与关于页真人区块同一人
2. `blog/[slug]/page.tsx` 的 Article JSON-LD 中 author 用 `Person`（name + 可选 url 指向 /about）
3. 文章页尾加作者小卡：头像 + 名字 + 一句话（"义乌拉链工厂外贸负责人，处理过 XX+ 国家的订单"）

## 三、首页信任元素（轻量）

首页现有「3/5/8 号 · 金属/树脂/尼龙 · 服装/箱包/鞋帽」信息条，About 页有 1992/30+年/50+国家数字卡。把两者合并升级：首页信息条改为四格数字：**Since 1992 · 50+ 国家 · 3/5/8 号全规格 · 12h 询盘响应**（5 语言）。数字与 About 页一致，不夸大。
