## 二、字体（先做样张给用户选）

用 `next/font` 自托管（不用 Google Fonts CDN，国内访问和隐私都更稳）：

- **方案 A（推荐）**：中文 Noto Sans SC（思源黑体），拉丁 Inter。标题 700 weight + `tracking-tight`，正文 400
- **方案 B**：全站只上 Inter 管拉丁与数字，中文回退系统苹方/微软雅黑（成本最低，中文效果依赖系统）
- 实施：`src/app/[locale]/layout.tsx` 里 `next/font/google` 引入 → CSS 变量 → Tailwind v4 的 `@theme` 里映射 `--font-sans`
- ⚠ 中文字体包大：Noto Sans SC 用 `subsets` 拉丁 + `display: 'swap'`，中文字形按 unicode-range 分片是 next/font 自动处理的；构建后检查字体文件不超过合理体积，ar/ru 字形覆盖要验证
- **交付方式**：做一版截图（首页 hero + 一个分类页）给用户对比选择，用户点头后全站铺开

## 三、配色 tokens（同样先出样张）

方向：从"通用蓝"转向呼应产品的**深藏青/石墨 + 黄铜金点缀**：

```css
/* Tailwind v4 @theme 示意 */
--color-brand-900: #0f1b33;  /* 深藏青：现 blue-900 的位置（导航深底、页脚） */
--color-brand-700: #1e3a8a;  /* 主行动色：按钮、链接（接近现 blue-700，平滑过渡） */
--color-accent:    #b8860b;  /* 黄铜金：小面积点缀——标签、hover 下划线、图标 */
--color-surface:   #f8f9fb;  /* 浅灰底 */
```

原则：
- 金色**只做点缀**（细线、小标签、hover 态），大面积金色会显廉价
- 先全局替换蓝色系变量观察整体，再逐页微调
- RTL（ar）与深色页脚的对比度用 WCAG AA 校验（正文 ≥4.5:1）
- **交付方式**：改完出首页+分类页+产品中心三张截图给用户拍板

## 五、产品详情页「产品实拍」紧凑化

文件：`src/app/[locale]/products/[slug]/page.tsx` 产品详情分支的 gallery 渲染。

- 现状：每条 `ProductGalleryItem` 一行（图左文右），6 条拉出 6 屏长度，右侧空白多
- 改为：`grid grid-cols-1 sm:grid-cols-2 gap-6` 的卡片网格，每卡 = 图上（ZoomableImage，h-56 sm:h-64 object-cover）+ 标题 + 两行描述
- 效果：页面长度减半，更像产品画册；手机端单列自然降级
- 保留每张图的点击放大

## 六、放大功能的可见性（ZoomableImage 组件）

文件：`src/components/ZoomableImage.tsx`。

- 图片容器右下角叠加半透明放大镜图标（`absolute bottom-2 right-2 bg-black/40 text-white rounded-full p-1.5`，SVG 放大镜，`pointer-events-none`）
- hover 时图标高亮 + 图片轻微 `brightness-95`
- 图标由 prop `showHint`（默认 true）控制，海报大图可关
- 无障碍已有 aria-label，保持

## 八、执行顺序与交付节奏

1. 第一批（无审美争议，直接做）：五、六、七节 + hero priority → 构建验证 → 截图给用户 → commit
2. 第二批（要用户拍板）：字体样张 → 配色样张 → 用户选定后全站应用 → commit
3. 第三批：首页改版（依赖配色定稿）→ 分节提交，每节截图确认
4. 每批都全语言抽查：`/zh`、`/`（en）、`/ar`（RTL 重点）三个语言 × 改动页面
