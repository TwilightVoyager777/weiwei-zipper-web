# 03 · 内容策略与 30 篇选题库

> 前置阅读：`00-总览与执行顺序.md`。建议先完成 `04-三篇优先文章.md` 再进入本文档的长期节奏。
> 类型：内容创作（长期执行）。本文档是选题库 + 写作标准，每次执行从库里取 1-2 篇产出。

## 一、博客系统现状

- 文章是 markdown 文件：`content/blog/{locale}/{slug}.md`，5 个语言目录（en/zh/es/ru/ar）
- frontmatter 字段：`title` / `excerpt` / `date`（YYYY-MM-DD）/ `author` / `category` / `readTime`（分钟数）
- 同一篇文章 5 个语言用**相同文件名**；某语言缺文件时自动回退到 en（见 `src/site-data/blog-posts.ts`）
- slug 即文件名，会出现在 URL：`/blog/{slug}`（en）、`/{locale}/blog/{slug}`
- sitemap 自动收录，无需手动登记
- 已有 5 篇：closed-end-vs-open-end-zippers、how-to-choose-zipper-size-3-5-8、how-to-evaluate-a-zipper-supplier-in-yiwu、how-to-prepare-a-zipper-inquiry、yiwu-zipper-wholesale-guide

## 二、内容标准（每篇必须满足）

1. **语言顺序**：先写 en（主战场），再 zh；es/ru/ar 只翻译表现好的文章（GSC 有曝光后），不是每篇都翻——质量差的翻译比没有更糟
2. **篇幅**：en 正文 1200–2000 词。以把问题讲透为准，不注水
3. **独有信息硬性要求**（至少一样，这是和 AI 水文的区别）：
   - 自家实拍图（`public/products/` 已有大量素材，或让用户新拍）
   - 工厂一手数据：真实的规格毫米数、打样时长、MOQ 逻辑、生产流程
   - 真实客户场景（匿名化）
4. **数字必须真实**：尺寸、MOQ、交期写进文章前向用户确认；未确认处留 `<!-- TODO(用户确认): xxx -->`，禁止编造
5. **内链 ≥3 处**：链向相关产品分类页/产品页/其他文章，锚文本用自然描述（"our #5 metal zippers" 而非 "click here"）
6. **结尾固定结构**：一段简短的工厂介绍（1992 年、义乌、三大材质）+ CTA 链到 `/quote`
7. **FAQ 段落**：文末 3-5 个 Q&A（这些问题本身就是长尾搜索词）
8. **图片**：每篇 ≥3 张，alt 用描述性英文，文件放 `public/blog/{slug}/` 并走 WebP 压缩标准（最长边 1600px q82）
9. **frontmatter 规范**：date 用真实发布日；author 用真实人名（和 06 文档的作者建设一致）；category 从 `guide` / `comparison` / `sourcing` / `industry` 四选一
10. 标题里含主关键词但像人话：`Zipper Size Chart: #3 vs #5 vs #8 (with mm Measurements)` ✅

## 四、内链规则（每篇发布时执行）

1. 新文章 → 相关分类页/产品页 ≥2 条、相关旧文章 ≥1 条
2. **反向**：发布后，回到 1-2 篇相关旧文章/产品页，加一条指向新文章的链接（很多人忘了这步，旧页面的权重传不过来）
3. 分类页（如金属拉链）适合长期挂一个「相关阅读」小节，链 B1/A1 这类常青文章

## 五、发布节奏与流程

- 节奏：**每周 1 篇 en**（可接受两周 1 篇，但要稳定；一次性灌 10 篇再停更是最差模式）
- 单篇流程：从库里取题 → 向用户确认该篇需要的事实数字/新照片 → 写 en → 写 zh → commit push → 在 GSC 请求收录该 URL → 回链旧文
- 每月复盘：GSC「效果」按页面过滤 blog，找出：有曝光没点击（改 title）、排 8-20 名（增补内容冲首页）、意外词（加进选题库）

## 六、验收标准（单篇）

1. 满足第二节全部 10 条标准，`npm run build` 通过
2. `curl -s localhost:3000/blog/{slug}` 200，且 title/描述正确
3. 图片全部 WebP 且 <300KB
4. 内链与回链完成
5. commit + push，不加 AI co-author；收尾确认 3000 服务在运行
