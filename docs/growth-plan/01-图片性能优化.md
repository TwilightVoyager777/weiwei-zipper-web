## 二、转换标准

- 目标格式：**WebP**（Next.js `<Image>` 会再做按需缩放，但源文件必须先减肥）
- 最长边 ≤ **1600px**（logo 例外，见下）；质量 **q82**（照片）/ **q86**（海报或有文字的图）
- 带透明通道的 PNG（logo）：转 WebP 时保留 alpha（`Image.open(src)` 后**不要** `.convert('RGB')`，用 `RGBA`）
- Logo 特殊处理：页头显示尺寸很小，源图缩到最长边 **512px** 足够；同时保留一份 256px 版本可选
- 项目内已有的转换先例（PIL / Python3，本机已装）：

```python
from PIL import Image

def convert(src, dst, max_px=1600, quality=82, keep_alpha=False):
    im = Image.open(src)
    im = im.convert('RGBA' if keep_alpha else 'RGB')
    if max(im.size) > max_px:
        im.thumbnail((max_px, max_px), Image.LANCZOS)
    im.save(dst, 'WEBP', quality=quality, method=6)
    print(dst, im.size)
```

## 三、执行步骤

### 步骤 1：转换并替换引用
对上表每个文件：
1. 转成同目录同名 `.webp`（如 `public/hero/tanwei.png` → `public/hero/tanwei.webp`）
2. 全局搜索旧路径的引用并改为新路径：
   ```bash
   grep -rn "tanwei.png\|weiwei-zipper-logo.png\|boost.jpg\|bag.png\|pf.png\|fsf.png\|resin-zipper-main.png\|cloth.png\|metal-zipper-main.png\|profile.png" src/
   ```
   引用可能出现在：`src/site-data/product-catalog.ts`（PRODUCT_IMAGES 等）、`src/site-data/site-content.ts`、各页面组件、`src/components/` 的 Header/Footer
3. 确认无引用后删除旧文件（git 里有历史，可恢复）
4. **例外**：如果某文件在 `src/app/[locale]/layout.tsx` 的 metadata（openGraph/icons）里被引用，OG 图规范另见 `02-技术SEO与元信息.md`，此处只做压缩替换

### 步骤 2：首屏 LCP 专项
1. 找到首页 hero 的 `<Image>`（`src/app/[locale]/page.tsx`），加 `priority` 属性（消除懒加载延迟，让浏览器最优先请求）
2. Header 里的 logo `<Image>` 加 `priority`
3. 检查首页首屏范围内的其他图片（如有）同样加 `priority`；**首屏以下的图不要加**（priority 滥用反而挤占带宽）

### 步骤 3：占位体验（可选加分项）
产品中心和分类页的图片较多，懒加载时会出现灰块。给关键列表图加模糊占位：
- 方案 A（简单）：容器已有 `bg-gradient-to-br from-blue-50 to-gray-100` 底色，保持即可
- 方案 B（更好）：用 `plaiceholder` 或构建期生成 base64 blurDataURL，给 `<Image placeholder="blur" blurDataURL={...}>`。如果引入依赖成本高，跳过，不强求

## 四、验收标准

1. `find public -type f \( -name "*.png" -o -name "*.jpg" -o -name "*.jpeg" \) -size +300k` 输出为空（WebP 海报 ≤200KB 可保留）
2. `npm run build` 通过（TS 校验 = 引用路径全部正确）
3. 重启服务后抽查以下页面 200 且图片正常显示（对照浏览器或 curl 图片路径）：
   - `/` 和 `/zh`（hero、logo）
   - `/zh/products`（6 分类卡 + 产品卡）
   - `/zh/products/metal-zippers`（海报、齿色区）
   - `/zh/about`
4. 首页 HTML 里 hero 图的 `<img>` 带 `fetchpriority="high"`（priority 生效的标志）：
   ```bash
   curl -s http://localhost:3000/zh | grep -o 'fetchpriority="high"' | head -2
   ```
5. 提交并 push（提交信息示例：`Compress legacy images to WebP and prioritize LCP images`），**不加 AI co-author 尾行**
6. 收尾时确认 3000 端口服务在运行

## 五、红线提醒

- 不要动 `public/products/{metal,resin,nylon}/` 下已优化的 WebP
- 不要动项目外的 `Photo/` 照片库
