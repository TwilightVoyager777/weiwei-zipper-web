## 文章二：拉链尺码对照表

- **slug**：`zipper-size-chart-3-5-8`（⚠ 与旧文 how-to-choose-zipper-size-3-5-8 主题相近但意图不同：旧文是"怎么选"，本篇是"查数据的参考表"。两篇互链，不合并）
- **主关键词**：zipper size chart；次级：#5 zipper size in mm, zipper gauge, what do zipper numbers mean
- **meta title**：Zipper Size Chart: #3, #5, #8 in mm (What Zipper Numbers Mean)
- **meta excerpt**：What do zipper sizes #3, #5 and #8 actually mean? Complete size chart with teeth-width measurements in mm, typical uses, and how to identify a zipper size from a garment.
- **为什么先写**：`zipper size chart` 是这个行业搜索量最大的信息词之一，而多数结果页是缝纫爱好者博客，工厂实测数据 + 实拍能做出差异
- **篇幅**：1200–1600 词

### 大纲
1. **开头**：拉链号数指的是闭合后链齿的宽度（毫米），不是长度——先纠正最常见误解
2. **H2: Zipper Size Chart（核心表格）**：

   | Size | Teeth width (closed) | Typical tape width | Common uses |
   |---|---|---|---|
   | #3 | ~4.5 mm | ~25 mm | 连衣裙、裤装、内袋 |
   | #5 | ~6 mm | ~32 mm | 夹克、箱包主仓、鞋靴 |
   | #8 | ~8 mm | ~38 mm | 重型箱包、行李、帐篷 |

   ⚠ **表中数字是行业常见参考值，发布前必须让用户用自家产品实测确认并替换**，这正是本文的差异化价值（"measured at our factory"）
3. **H2: How to Identify the Size of an Existing Zipper**：拉头背面刻号（slider 底部通常压有 3/5/8）+ 卡尺量齿宽两种方法；📷 **需要用户拍 2 张**：拉头刻号特写、卡尺量齿宽
4. **H2: Does Size Differ by Material?**：同号数下金属/尼龙/树脂的手感与厚度差异（工厂视角，一段一材质）
5. **H2: Choosing Size by Application**：简短，链向旧文 how-to-choose-zipper-size-3-5-8 承接"怎么选"
6. **FAQ**（4 问）：Is a #5 metal zipper the same width as a #5 nylon? / What size for a backpack? / Can zipper length be customized for any size? / What's the biggest size you produce?
7. **CTA**
