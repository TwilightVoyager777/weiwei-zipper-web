## 一、目标

通过 Google 自然搜索（不投广告）获取海外 B2B 拉链采购客户的询盘。目标客户：箱包厂、服装厂、鞋帽厂、小品牌、外贸采购商。核心策略：**放弃大词（zipper manufacturer 首页是 YKK/SBS/Alibaba），用长尾信息型内容 + 真实工厂实拍图建立流量和信任，把读者转化为询盘。**

## 三、站点技术档案（每个 agent 必读）

### 技术栈
- **框架**：Next.js 15 App Router + React 19 + TypeScript（strict 模式，编译即校验）
- **样式**：Tailwind CSS v4
- **国际化**：next-intl。5 个语言：`en`（默认，URL 无前缀）、`zh`、`ru`、`es`、`ar`（RTL）。URL 规则：英文 `https://www.weiweizipper.com/products`，其他语言 `https://www.weiweizipper.com/{locale}/products`
- **部署**：Vercel，push 到 `master` 分支自动部署上线
- **域名常量**：`src/config/site-constants.ts` 里的 `SITE_URL = 'https://www.weiweizipper.com'`

### 内容数据的架构约定（改 product-catalog.ts 必看）
- 产品数据按语言分对象：`productItems`（zh）、`productItemsEn/Es/Ar/Ru`，分类同理 `categoryContent*`，最后聚合成 `*ByLocale`
- **es/ar/ru 的 categoryContent 用展开 En 对象再覆盖的写法**（`...categoryContentEn.xxx`），所以图片路径这类共享字段只需在 zh + en 两处维护
- 类型是 `Record<ProductSlug, ...>`：新增一个产品 slug 后，5 个语言对象都必须补全条目，否则 `npm run build` 直接报错——这是刻意设计，防漏翻
- 现存的 `metal-zipper-3` 等旧产品是**模板占位**，用户将来会要求删除；新内容一律新增，不要改模板

## 四、全局红线（违反任何一条都算任务失败）

### 仓库与流程红线
1. **git 提交信息里绝不出现 Claude / AI co-author 尾行**（`Co-Authored-By: Claude...` 一律不加）
2. **验证完不许关闭 3000 端口的服务**，用户要持续在浏览器查看；只在重新构建前 kill，构建后立即重启
3. `npm run build` 和正在运行的 dev/start 服务**不能同时操作同一个 `.next`**，先停后建
4. 改动完成即 commit + push 到 master（自动部署），提交信息用英文祈使句
5. `Photo/` 目录（项目外的照片库）只读，不属于构建产物，不要动
6. 删除或重命名任何已上线 URL 必须配 301 重定向（next.config 的 redirects）

### SEO 红线（所有内容类任务适用）
1. **禁止购买外链**、链接包、PBN——处罚风险远大于收益
2. **禁止机器翻译批量铺页**——es/ru/ar 内容宁缺毋滥，质量必须像母语者写的
3. **禁止门页**——不做 "zipper supplier USA/UK/Germany"×N 的复制页面
4. **禁止关键词堆砌**——标题、alt、正文都用自然语言，一个页面一个主关键词
5. **禁止无独有信息的纯 AI 水文**——每篇文章必须包含：真实实拍图、工厂一手数据（规格/流程/时间线）、或真实案例，至少一样
6. **禁止贬低竞品**——可以写 "When you need a YKK alternative" 角度，不写"我们比 YKK 好"
7. 已收录 URL 不轻易改；frontmatter 的 date 不造假（不把旧文改成新日期骗新鲜度）
8. 内容数字必须真实：尺寸毫米数、MOQ、交期等写进文章前先向用户确认，**宁可留 `TODO(用户确认)` 占位也不编造**

## 五、成功度量

- **注册 Google Search Console 后每周看一次**：曝光量、点击量、平均排名、具体查询词
- 有曝光没点击的词 → 改该页面的 title/description
- 意外获得排名的词 → 顺着写深化文章
- 询盘表单和 WhatsApp 点击是最终指标，GA4 里给 `/quote` 提交和 WhatsApp 链接点击配置事件
- **预期节奏**：长尾文章 2-4 个月出排名，6-12 个月形成稳定流量。前 3 个月看收录和曝光，不看点击量焦虑
